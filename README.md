# Dayweave · 拾日

从日常对话中，拾起值得记住的事。

An ambient personal secretary that turns everyday conversations into a lasting text archive and thoughtful insights.

Dayweave 是一套尽量无需操作的个人秘书系统：通过随身设备采集日常对话，把声音转成文字档案，再交给 Agent 结合历史上下文做整理、总结、建议和洞察。

音频是处理过程中的临时材料。文字是长期留下的记忆。

> **当前状态：产品定义阶段。** 本仓库目前包含产品文档，尚无可安装 App、运行中的后端或已验证的设备适配。下文描述的是计划行为。

## 为什么做这个项目

一天里值得留下的内容，经常散落在随口说出的想法、与人的交谈，以及反复提起却没有想清楚的问题中。主动记笔记需要额外动作，等晚上回忆又容易遗漏。

我们希望有一位安静的秘书，帮助保存这些线索，并在适当的时候把它们整理出来：今天经历了什么，一个想法如何逐渐成形，什么事情需要跟进，以及近期的生活里有什么值得留意的模式。

## 两个独立步骤

```text
采集输入：耳机 → 手环 → 手机
                   ↓
          本地轻量降噪与人声检测
                   ↓
       停顿结束片段，单段最长 15 分钟
                   ↓
第一步：云端转写 → 可靠保存文字档案 → 清理临时音频
                   ↓
第二步：Agent 阅读文字档案与历史上下文 → 整理与洞察
```

### 1. 忠实记录

- 按耳机、手环、手机的顺序，选择实际可持续采集的输入。
- 手机通常在口袋中，因此穿戴设备收音是重要的产品要求。
- 本地做人声检测和适度降噪，避免无声片段占用识别资源。
- 持续没有人声时结束当前片段；持续讲话最长每 15 分钟提交一次转写。
- 片段结束后继续监听，下一段讲话无需重新手动启动。
- 转写保留时间、来源和可用的说话人分段；无法确认的内容保留不确定性。
- 文字可靠保存后，删除对应临时音频。

### 2. 理解与整理

Agent 的输入是文字档案，职责不限于提取待办：

- 总结一天的经历与重要对话。
- 整理零散的想法、决定和未解决的问题。
- 找出跨天反复出现的主题、联系与矛盾。
- 结合个人目标和历史处境，提出有依据、可纠正的建议。
- 记录承诺与需要跟进的事情。

整理结果与原始转写分开保存，并关联对应文字出处。Agent 不改写原始档案，也不需要每天凑齐固定栏目。

## 轻量的数据边界

| 数据 | 处理原则 |
| --- | --- |
| 音频 | 仅为转写临时保留，不建立长期录音库 |
| 待转写片段 | 断网或失败时短期缓存，设置容量与有效期 |
| 原始转写 | 长期文字档案，保留来源与不确定内容 |
| Agent 整理 | 独立于原始转写，可重新生成和纠正 |

云端转写需要接收音频内容。“不长期保存音频”同时约束我们自己的处理链路，并作为第三方识别服务的选型与配置条件；不声称已经验证供应商的数据留存行为。

## 实现方向

- 原生安卓 App：Kotlin + Jetpack Compose。
- 采集、临时缓存和转写任务相互独立，断网不阻塞采集。
- 允许使用云端 AI，优先识别效果和使用便利。
- 文字档案优先采用便于迁移、检索和交给 Agent 的开放格式。
- Agent 整理独立运行，识别模型和整理模型可分别更换。

详细边界、产品意图和验收方向见 [产品定位与意图](docs/PRODUCT.md)。

## 开发顺序

1. 调查耳机、手环收音链路，确认真机持续采集条件。
2. 打通采集、轻量处理、分段转写、文字归档和音频清理。
3. 接入 Agent，生成带文字出处的整理、总结和洞察。
4. 验证全天使用中的耗电、切换、中断恢复和提醒体验。

各阶段均尚未完成。设备接入方式、模型服务、Agent 运行位置及缓存参数将在实现前进一步确定。

## 使用边界

记录应在参与者知情、适合录音的场景中进行，并提供容易找到的暂停与删除入口。“无感知”指减少使用者反复操作的负担，不代表隐藏录音状态。
